

 # Student Data Organizer

 ## Project Description

The Student Data Organizer is a simple Python project used to manage student information. It allows users to add, display, update, and delete student records easily.

## Objective

The main objective of this project is to organize student data and practice Python programming concepts.



 ## Features

Add Student

Display All Students

Update Student Information

Delete Student

Display Subjects Offered

Exit the Program
 Student Details

## Student ID

Name

Age

Grade

Date of Birth

Subjects
